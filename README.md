## 快速开始

1. 在手册目录中找到算法，阅读使用条件、接口和易错点。
2. 打开该条目的完整代码链接，复制对应的 `.cpp` 文件；所需依赖已经包含在文件内。
3. 在 `solve()` 中填写题目逻辑。默认读取测试组数 `T`，单组题删除 `cin >> T;`。
4. 使用 GNU C++17 编译并运行。每次使用一个算法文件，不要将所有 `.cpp` 一起链接。

普通数组和顶点默认从 1 开始编号，数组查询默认使用闭区间 `[l,r]`；字符串等例外以对应算法说明为准。

## 维护入口

`tools/` 集中保存生成源、附录和维护脚本；`RBC_XCPC_算法模板/` 保存手册、独立代码和测试；`output/pdf/` 保存打印版产物。

长期内容修改应维护 `tools/handbook_data.py` 和 `tools/appendix.md`，再依次生成手册和打印版，避免直接修改生成结果后被覆盖。

- [编译与验证](RBC_XCPC_算法模板/README.md#编译与验证)：独立编译与启动检查、算法样例与对拍、目录与生成一致性检查。
- [维护与再生成](RBC_XCPC_算法模板/README.md#维护与再生成)：生成命令、打印依赖和字体环境。

算法按“同一问题同一节、不同方法分小标题和独立文件”组织，当前程序数量见[使用说明](RBC_XCPC_算法模板/README.md)，具体文件见[代码文件清单](RBC_XCPC_算法模板/代码文件清单.json)。
